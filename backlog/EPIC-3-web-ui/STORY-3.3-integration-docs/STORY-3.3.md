# STORY-3.3 Интеграция и документация

Като обучаващ се искам README-то и демото да включват UI-я, за да видя
„същият total, пет начина“ и да разбера къде седи UI-ят спрямо хексагона.

## Критерии за приемане

- README има секция UI: инсталация, `npm run ui`, proxy, `npm run ui:test`.
- Диаграмата на хексагона показва браузъра като клиент на HTTP адаптера, извън хексагона.
- `npm run pack` включва `ui/` (без `node_modules` и `dist`).
- Демото е прието ръчно: `hh-1` → `14 239.73`, `hh-404` → грешка.
