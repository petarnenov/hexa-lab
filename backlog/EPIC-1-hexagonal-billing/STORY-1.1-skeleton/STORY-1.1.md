# STORY-1.1 Скелет на проекта

Като обучаващ се искам минимален TS проект с ESM, tsx и node:test, за да пиша код без framework-и.

## Критерии за приемане

- `npm install && npm run typecheck` минава върху празен `src/`.
- Скриптовете `cli`, `http`, `test`, `typecheck` съществуват и работят на macOS и Linux.
