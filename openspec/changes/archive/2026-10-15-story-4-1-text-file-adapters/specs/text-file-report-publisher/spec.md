# Spec Delta

## Purpose

Определя publisher-а, който пази всеки отчет като блок в текстов файл.

## ADDED Requirements

### Requirement: Отчетът се добавя като блок в текстов файл
Publisher-ът SHALL се конструира с път и при всяко `publish` SHALL добавя
към файла (без да презаписва) блок: ред
`household <id> | <from>..<to>`, по един ред
`<accountId> | <accountName> | <aum> | <feeScheduleId> | <fee>` за всеки ред
на отчета, ред `total | <total>` и празен ред. Липсващ файл SHALL се създава.
`publish` SHALL резолвва с `undefined`.

#### Scenario: Формат и създаване
- **GIVEN** несъществуващ файл във временна папка и отчет за `hh-1` с два реда
- **WHEN** отчетът бъде публикуван
- **THEN** файлът съдържа точно блока от четири реда плюс празен ред

#### Scenario: Добавяне
- **GIVEN** файл със съдържание `earlier`
- **WHEN** същият отчет бъде публикуван два пъти
- **THEN** файлът е `earlier`, последвано от блока два пъти

### Requirement: Неуспешен запис е грешка с пътя
Ако файлът не може да бъде записан, `publish` SHALL отхвърля с обикновен
`Error`, чието съобщение съдържа пътя.

#### Scenario: Липсваща папка
- **GIVEN** път в несъществуваща папка
- **WHEN** отчет бъде публикуван
- **THEN** отхвърля със съобщение, съдържащо пътя
